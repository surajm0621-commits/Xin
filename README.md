# CodeLab – Online Coding Platform

Browser me chalne wala simple code editor: HTML, CSS aur JavaScript likho, live preview aur console dekho.

## Features
- HTML / CSS / JS tabs
- Live preview (auto-run) + console output
- Code browser me auto-save (localStorage)
- Download as `.html`
- Mobile friendly

## Run karna
`index.html` ko browser me kholo. Koi install ya server nahi chahiye.

## GitHub Pages pe live karna
1. Repo ki Settings kholo
2. Pages -> Source: `main` branch, `/ (root)`
3. Save karo, link ban jayega: `https://USERNAME.github.io/REPO/`
